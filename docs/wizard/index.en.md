# Guided path

The path to learn service-app by building: each step is a single, standalone
page, with copyable examples. At the end of each step you find the link to
the next one.

1. **[Create a form](step-1-create-form.md)** — builder drag&drop or plugin: from empty form to dashboard card.
2. **[Components and features](step-2-components.md)** — Form.io components and custom Ozon ones: embedded tables, remote selects, logic, files.
3. **[Actions and groups](step-3-actions.md)** — the action router, menu, dashboard, default actions and action ACL groups.
4. **[External services](step-4-external-services.md)** — service registry, companion services, core webhooks, remote selects against external URLs.
5. **[Workers and Camunda](step-5-workers-camunda.md)** — application gateway, BPMN, `ozon_camunda_worker` and Keycloak M2M.
