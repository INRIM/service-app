# Percorso guidato

Il percorso per imparare service-app costruendo: ogni step è una pagina unica
e autonoma, con esempi copiabili. A fine step trovi il link al prossimo.

1. **[Creare un form](step-1-create-form.md)** — builder drag&drop o plugin: dal form vuoto alla card in dashboard.
2. **[I componenti e le funzionalità](step-2-components.md)** — i componenti Form.io e quelli custom Ozon: tabelle incorporate, select remote, logica, file.
3. **[Le action e i gruppi](step-3-actions.md)** — l'action router, menu, dashboard, le action di default e i gruppi ACL sulle action.
4. **[I servizi esterni](step-4-external-services.md)** — service registry, companion service, core webhooks, select remote verso URL esterni.
5. **[I worker e Camunda](step-5-workers-camunda.md)** — gateway applicativo, BPMN, `ozon_camunda_worker` e M2M Keycloak.
